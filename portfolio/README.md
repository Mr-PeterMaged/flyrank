# portfolio/

Lives in the same repo as the FlyRank internship work, deployed as its own Vercel project
(same pattern as `paper/`): import this repo on Vercel, set **Root Directory = `portfolio`**,
and it gets its own domain, independent of the internship paper's deployment.

Sitemap (per the reviewed feedback in `../Portfolio_Sitemap_Feedback.docx`, bank-HR-recruiter
read): **HERO → WORK (3-4 curated projects) → ABOUT + SKILLS → CONTACT**.

See [`CASE_STUDY_PLAYBOOK.md`](CASE_STUDY_PLAYBOOK.md) before adding or updating any project
card in WORK — it's the repeatable habit, not a one-off.
